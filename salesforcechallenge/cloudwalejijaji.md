
# 🚀 Set Up Visual Studio Code for Salesforce Development by 

Follow these steps to install and configure Visual Studio Code (VS Code) with the Salesforce CLI and extensions.

For detailed tutorials and Salesforce setup guidance, visit my YouTube channel below 👇  

---

## 🧩 1. Download & Install Visual Studio Code

👉 [Download VS Code](https://code.visualstudio.com/docs/terminal/getting-started)

1. Go to the link above.  
2. Download and install VS Code for your operating system (Windows, macOS, or Linux).  
3. Once installed, launch **Visual Studio Code**.

---

## ⚙️ 2. Install Salesforce CLI

👉 [Install Salesforce CLI](https://developer.salesforce.com/tools/salesforcecli)

1. Download the Salesforce CLI installer for your OS.  
2. Follow the setup instructions on the site.  
3. After installation, open your **Command Prompt** or **Terminal** and verify the installation:

   ```bash
   sf update
## 🧠 3. Install the Salesforce Extension Pack in VS Code

1. Launch **Visual Studio Code**.  
2. On the left sidebar, click the **Extensions** icon (or press `Ctrl+Shift+X`).  
3. In the search field, type: Salesforce Extension Pack
4. <img width="1144" height="336" alt="image" src="https://github.com/user-attachments/assets/f81d0788-767b-481a-b5f7-f5a7396252fb" />
5. 4. Select **Salesforce Extension Pack** from the results.  
6. Click the **Install** button at the top of the details window.  

📸 *Example:*  
> The green **Install** button appears at the top of the extension details page.

## 🔁 4. Restart Visual Studio Code

Once the installation is complete:

- Close **VS Code**.  
- Relaunch it to ensure the Salesforce extensions are properly loaded.
